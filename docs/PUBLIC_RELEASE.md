# 源码分发范围

仓库包含 RTL、固件、主机工具、测试、约束、链接脚本、设备树、模型部署数据
和具有独立许可的第三方源码及资源。

当前版本统一使用通用技术命名。命名调整覆盖路径、模块、软件标识、协议字符串、
图节点与模型元数据；ONNX 数值张量保持不变。构建身份与文件哈希按当前内容登记。

保留的参考快照、辅助工具和子清单属于各自技术流程的输入或记录。
根目录 `SOURCE_FILES_SHA256.json` 描述当前分发文件，根校验器仅验证文件完整性。
历史子清单不能替代当前清单，也不能证明新构建或实板测试已经完成。

受限 IP、商业 ROM 和需要重建的旧初始化镜像未分发。许可证与构建依赖
分别见根许可索引、`BUILD.md` 和 `GENERATED_INPUTS.md`。
