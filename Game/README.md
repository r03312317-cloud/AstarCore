# 图形外设验证子系统

本目录将 LiteNES 软件模拟器适配到 RV32 平台，用于验证 GPIO 输入、
定时器、DDR 双帧缓冲和 HDMI 显示链路。

- `source/`：平台、适配层、模拟器、主机工具与测试。
- `baseline/`：参考源码布局。
- `audit/`：源码与构建核对工具。
- `reports/`：保留的源码文件列表。

软件以定时器提供节拍，采样按键并更新状态，绘制后台帧缓冲，再通过
显示提交与完成确认切换缓冲区，避免写入正在扫描的前台缓冲。

构建入口为 `source/tools/build_mario.py`。商业 ROM 数组及含 ROM 的
DDR 初始化数据没有分发，应使用有权使用的 ROM 或自制测试程序。
当前命名版本需重新生成软件和 FPGA 配置，并重新验证运行结果。

第三方来源及许可见 `source/THIRD_PARTY.md` 和仓库根目录第三方索引。
