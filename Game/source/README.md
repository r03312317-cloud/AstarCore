# RV32 图形平台与模拟器适配

`soc/` 提供 CPU、缓存、DDR、输入和显示相关 RTL；`port/` 提供裸机运行环境，
`src/` 为适配后的软件模拟器，`upstream/litenes/` 保存上游参考代码。
`boot/`、`tools/`、`tests/` 分别用于装载、构建和验证。

参考平台使用 100 MHz CPU；DDR 双帧缓冲为 640×360 RGB565，
NES 256×240 画面缩放为 480×360 并居中显示。
帧发布次数以硬件确认完成为准，与 HDMI 扫描刷新率分别统计。

构建从 `tools/build_mario.py` 开始，先提供合法 ROM、匹配的平台输入和工具链。
厂商 IP、商业 ROM 与原位流未分发。参考快照中的旧构建身份只作来源信息，
当前命名版本应重新生成镜像与测试数据。

LiteNES 与适配代码保留上游声明；来源链与许可见 `THIRD_PARTY.md`。
